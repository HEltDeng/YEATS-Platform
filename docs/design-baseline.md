# 固定视觉基准与原生适配

原型文件及 SHA-256 见 reference-manifest.json；原件位于源码外参考目录，未改写。实际打开了三个角色端，按页面 DOM 清点了34个主屏、324个控件候选；候选数不等同已验收操作数。

沿用主色 #FF7A00、渐变 #FF8A00/#FFB524/#FFC93C、背景 #FFF8F0、正文 #3B2A17、次文字 #9C8A76、浅边线 #FFE6C7；卡片14px圆角、主要容器18px圆角、克制橙色阴影。原生样式采用2倍rpx值；保留首页8入口、学情列表、课时统计、周课表、知识树和业务弹层结构。

移除原型外层逐屏导航、模拟手机壳/状态栏和三端任意切换入口。使用微信真实导航、胶囊、安全区和4个原生 Tab；PC 业务导航在后续阶段保留，未误删为演示工具。

差异记录：

- 微信身份校验与手机号授权分成两步，以适配真实官方 code 流程；未授权手机号时保留退出入口。
- 模拟器展示明确的开发环境提示及独立测试身份，正式构建不能带测试入口。
- 示例人名、余额、公告、经营宣传不复制成真实业务；用受控测试资料或真实空状态。
- 课表时区统一按中国标准时间，窄列显示时分，不把完整时间戳挤入格子。
- 家长“我的”、资料、设置、课程介绍和详情是正式路由；不依赖 Demo 外层导航。
- 图片附件改为真实权限链接的内嵌预览，点击打开原生预览；不使用静态假缩略图。

本轮已做主要页面视觉初检并修复上述布局/状态问题。完整逐控件视觉验收尚未结束，尤其文档预览兼容和最后补充状态需要后续实机复核，不能宣称像素级全部一致或用户已经验收通过。
