# 跨端业务与当前验收边界

| 业务 | 创建者 | 处理者 | 家长查看/操作 | 状态与当前证据 |
|---|---|---|---|---|
| 身份与监护关系 | 微信身份；机构预登记手机号关系 | 后端真实手机授权核验 | 登录；自动关联；切换 | 实际 wx.login/code2Session/YEATS 会话成功；手机号本人授权未完成；越权 API 测试通过 |
| 作业 | 授权老师 | 老师批改/退回 | 真实图片/文字提交 | todo → submitted → returned → submitted（revision+1）→ graded；模拟器实操，老师动作由受控脚本调用共用业务函数 |
| 测试 | 授权老师 | 老师维护 | 查看入门/出门测和音频图片 | 已发布可见；本轮使用受控数据库内容；老师 UI 未开发 |
| 签到与课时 | 设备规范事件或授权老师 | 去重、匹配、人工更正 | 只读明细与课时 | 排课、Attendance、HourEntry 分离；请假/缺勤不扣课时；补签按课节；更正追加流水；测试通过，真设备未联调 |
| 知识库 | 当前确认需求由平台维护 | 老师引用到班级 | 1–7 分类 + 第8层内容、搜索、预览/下载 | 同一资源引用；下架检查沿父分类生效；七类真实文件，视频无下载入口；8 层在模拟器展开 |
| 私密提问 | 家长 | 授权老师 | 提问、读取自己的问答 | 真实保存；家长间隔离；老师回复 UI 待阶段2 |
| 缺课补看 | 家长基于缺课记录申请 | 管理员决定起止时间 | pending → approved/rejected；到期不可观看 | 模拟器申请/播放；审核由受控脚本，平台 UI 未开发；原视频链接逐次权限复核 |
| 通知 | 共用业务事件 | 站内立即保存；订阅 Outbox 独立处理 | 未读、单条/全部已读 | 模拟器已读后重新进入为0；微信发送需模板及订阅授权；失败不回滚业务 |
| 约课/调课/报名 | 家长咨询 | 企微客服线下处理 | 查看配置的机构二维码 | 暂缺真实二维码；按确认需求不创建线上支付流程 |

接口级跨角色处理不能作为老师端或管理端界面已经交付的证明。受控测试账号在非 development 环境禁止启用，不参与真实微信失败回退。
