# YEATS 环境边界

本地开发已实际运行：Windows Python/FastAPI，独立 PostgreSQL 数据目录、角色和数据库，仓库外私密配置，仓库内被忽略的私有文件。入口为 scripts/start-local.ps1，数据库升级使用 Alembic。

临时验收服务器与客户生产环境尚未部署。不得把本机回环地址作为线上入口，不得默认复用腾讯云现有业务。部署前须提供只读资源审计、独立服务/数据库/账号/目录/文件命名空间方案与回滚步骤，并满足现有授权边界。

验收与生产配置通过独立环境变量注入，不读取本地开发凭据。必须明确 YEATS_ENVIRONMENT、PostgreSQL连接、HTTPS地址、文件根、微信配置和规则确认；生产禁止开发身份入口。当前本地文件适配器已实现，正式对象存储厂商适配和真实云联调未完成。

备份脚本 scripts/backup-local.py 仅在明确执行时生成数据库归档及私有文件zip，不打包秘密；现有备份/恢复说明见README，正式恢复演练尚未执行。开发源码回退不等于数据库可以随意降级。
